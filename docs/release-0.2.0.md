# Arctic Console 0.2.0 · Northern Bay practice

[Open the assignment](https://flaritycat.github.io/Arctic-Console-Open-Source-Project/practice.html) or [download the release and checksum](https://github.com/flaritycat/Arctic-Console-Open-Source-Project/releases/tag/arctic-console-v0.2.0). Extract the ZIP and open `practice.html` to work offline. Evidence Check remains available as `evidence-check.html`.

| Work | What this version provides |
| --- | --- |
| P02 | Repeatable archives from a clean checkout, an explicit file list, embedded notices, a source-commit manifest and a verifier for independently downloaded assets. [Release procedure](releasing.md) |
| P04 | An original fictional assignment about two averages drawn from different sample locations, with evidence, teaching objectives and criteria for the reader. [Case specification](practice-case.md) |
| P05 | A four-step author workflow, explicit draft export and resume, and a separate reader view that opens a completed handover. No account or installation required. [Practice guide](practice-guide.md) |

Engineering checks cover malformed and modified records, evidence references, incomplete work, cancelled imports, keyboard field order, narrow layouts and a handover opened in a fresh browser session. The release procedure verifies the archive against the tagged source. The GitHub release records the artifact checksum and the specific workflow run.

**Limits:** The five observations are invented. The software does not grade free-text assessments, authenticate authors, send files or change real ownership. There is no automatic saving. Version 0.2.0 reads practice schema 1, Northern Bay edition 1. Automated browser checks are not P06 participant research, a WCAG conformance assessment or independent scientific validation.

For rollback, keep the [previous Evidence Check release](https://github.com/flaritycat/Arctic-Console-Open-Source-Project/releases/tag/evidence-check-v0.1.1). It does not read practice files; keep the 0.2.0 offline viewer for those. Maintainers should follow the [hosted rollback procedure](releasing.md) and preserve both tags.
